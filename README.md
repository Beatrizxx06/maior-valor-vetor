<h1 align="center">🔢 Maior Valor do Vetor</h1>

<p align="center">
  Programa em <b>C</b> que lê 5 números inteiros, encontra o maior valor e mostra em qual posição do vetor ele está.
</p>

<p align="center">
  <img src="https://img.shields.io/badge/C-0D1117?style=for-the-badge&logo=c&logoColor=A8B9CC" alt="C" />
</p>

---

## ⚙️ Como funciona

1. Lê 5 valores inteiros e guarda no vetor `v_lido`.
2. Assume que o primeiro elemento é o maior.
3. Percorre o restante do vetor e, sempre que encontra um valor maior, atualiza o maior valor e a posição.
4. Exibe o maior valor e o índice onde ele foi encontrado (em caso de empate, vale a primeira ocorrência).

### Exemplo

```text
Digite v[0] = 3
Digite v[1] = -2
Digite v[2] = 9
Digite v[3] = 4
Digite v[4] = 7

Maior valor: 9
Posicao: v[2]
```

## 🚀 Como executar

```bash
gcc maior_valor.c -o maior_valor
./maior_valor
```
